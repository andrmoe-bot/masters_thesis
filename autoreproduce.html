Introduction

Reproducibility is important for the advancement of science, but attempting to reproduce past results is a labor-intensive process without much reward for scientists. LLMs are a promising option to partially or fully automating this.

Method

This thesis is will decompose the task into 3 stages, based on the classification system by , and only implement stage 2.

The stages are:
  • Paper to code, R1->R2
  • Code repair and execution, R2->R4
  • Reproducibility assessment, IR4

The idea is to take papers with existing implementation, and separate out the most compute heavy stage, in such a way that multiple approaches to reproducibility assessment can be tried without having to rerun the whole experiment.

Reproducibility assessment is a difficult task to decompose, because the final assessment must take every aspect of the process into account, in order to assess whether the original paper's conclusion is correct. A task decomposition would be fragile, if errors stack up from stage to stage. I therefore think that a good decomposition would not delegate the task of making jugdements to multiple agents. It should instead have one agent assess every step for validity, and have other agents make this as easy as possible. These other agents must therefore contribute in ways that are independently verifiable.

In the case of the code repair agent, this means that it's not the agent's task to vouch that the repair is correct, bug free, or representative of the paper. It's job is to do trial and error to make the code run, to complete the experiment. The assessment agent shouldn't need to trust the code repair agent. It only needs to trust that the research artifacts were made with the script from the that the code repair agent submitted, and this can be done with human-written software.

A weakness with this decomposition is that the assessment agent might conclude that the code has a bug that invalidates the result. This would mean that compute was unnecessarily wasted. However, we can still keep the task decomposition by altering the order of operations in a way that is invisible to the agents.
